# 同花顺老师消息 · 安装流程

[安装演示视频（约 2 分钟，无音轨，18.75 MB）](https://github.com/jesson-hh/ths-teacher-chat/releases/download/v0.2.0/THSTeacher-install-demo-20261020-silent-20MB.mp4)

1. 打开 [下载安装包](https://github.com/jesson-hh/ths-teacher-chat/releases/latest)，下载 ZIP，完整解压到固定文件夹。
2. 先启动同花顺，再双击文件夹里的 **安装.exe**，确认位置后点击 **完成安装**。
3. 双击桌面 **同花顺老师消息**，在 **设置 → 约牛登录** 完成登录。

同花顺需要有一个名为 **老师消息** 的空白看板；已创建过就不用重建。

无需 Python 或命令行。请保留整个解压文件夹，包括 `_internal`。

日常通过顶部 **只看老师 / 全部聊天** 切换。组件进程运行时才会收消息。

提示缺少 WebView2 时，从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 安装运行时。
